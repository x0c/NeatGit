# NeatGit

NeatGit 是一个面向 macOS 的原生 Git 客户端，计划使用最新的 SwiftUI 从 0 到 1 构建。

目标是做一个现代、简洁、好用的桌面工具，让开发者可以更轻松地管理本地 Git 项目、查看变更状态，并完成常见的提交与推送操作。

## 产品方向

- 原生 macOS 体验：基于 SwiftUI 构建，界面简洁、轻量、符合现代 macOS 设计风格。
- 面向日常 Git 工作流：围绕项目发现、文件变更管理、提交、推送等高频操作设计。
- AI 增强：在合适的场景引入 AI，减少重复性输入和机械操作。

## 当前设想

### 1. 自动扫描本机 Git 项目

- 自动扫描电脑上的 Git 仓库。
- 聚合展示本地项目，降低手动维护项目列表的成本。
- 为后续统一入口管理多个仓库打基础。

### 2. 左侧项目列表布局

- 界面左侧展示 Git 项目列表。
- 支持快速切换当前仓库。
- 作为整个应用的主导航结构，承载多项目管理体验。

### 3. 图形化管理 `.gitignore` 与 `skip-worktree`

- 支持图形化展示 `.gitignore` 相关文件与配置。
- 支持图形化配置 `skip-worktree` 相关文件。
- 降低命令行操作门槛，让忽略规则和本地跳过跟踪策略更直观。

### 4. AI 辅助提交

- 支持 AI 快速生成 commit message。
- 在 commit 时自动 stage 文件。
- 支持默认自动 push，减少重复操作。

## 设计原则

- 简洁优先：避免复杂和拥挤的界面，聚焦核心操作。
- 原生优先：充分利用 SwiftUI 和 macOS 原生能力。
- 效率优先：尽量减少 Git 高频操作的步骤数。
- 可扩展优先：为后续增加更多 Git 能力预留结构空间。

## 当前状态

当前项目处于产品设想与基础搭建阶段，功能尚未开始完整实现。

后续将逐步推进：

- 信息架构与页面布局设计
- Git 仓库扫描能力
- 仓库详情与文件状态展示
- `.gitignore` / `skip-worktree` 图形化管理
- AI commit 工作流
